사용자 가이드

경찰청 AI 통합플랫폼(ISP)의 모든 기능을 이용하기 위한 표준 매뉴얼입니다. 계정 발급부터 모델 등록·운영, LLM 워크스페이스 활용, 그리고 비상 상황 대응까지 — 일선 수사관과 모델 개발자가 각자의 워크플로에 맞춰 필요한 절차만 골라 따라갈 수 있도록 구성되어 있습니다.

Section 01

시작하기

본 플랫폼은 경찰 내부망에서만 접속 가능합니다. 외부망·VPN 우회 접속은 자동 차단되며, 정보보안담당관실에 이상 접속 알림이 즉시 전송됩니다.

1) 계정 발급 절차

  1. 소속 부서장 결재
    「AI 통합플랫폼 이용 신청서」를 부서장 결재 후 정보화기획단에 제출합니다. 신청 시 업무 범위와 필요한 데이터 분류 등급(A/B/C)을 명시해야 합니다.
  2. PKI 인증서 등록
    경찰청 PKI 인증서를 발급받고, 단말기 보안 USB(보안USB-G3 이상)에 등록합니다. 인증서 없이는 로그인 단계로 진입할 수 없습니다.
  3. 2단계 인증 (OTP) 활성화
    최초 로그인 시 정부24 모바일 OTP 또는 하드웨어 OTP 토큰을 등록합니다. OTP 미등록 계정은 7일 후 자동 잠금됩니다.
  4. 역할(Role) 배정 확인
    시스템 관리자가 신청서에 기재된 업무 범위에 따라 역할을 배정합니다(VIEWER / ANALYST / DEVELOPER / APPROVER / ADMIN). 역할별 권한은 「데이터 보안 정책」을 참조하십시오.
처리 기간 일반적으로 영업일 기준 3–5일이 소요됩니다. 긴급 수사 목적의 임시 계정은 사이버수사대장 승인 후 24시간 내 발급되며, 유효기간은 14일로 제한됩니다.

2) 첫 로그인 체크리스트

  • 초기 비밀번호 변경
    대소문자·숫자·특수문자 조합 12자 이상. 직전 5회 비밀번호 재사용 불가.
  • 알림 채널 등록
    모델 승인 요청·드리프트 감지·인시던트 알림을 받을 채널(폴리스원톡 / 내부 이메일)을 선택합니다.
  • 워크스페이스 선택
    초기 화면에서 MLOps 콘솔 또는 LLM 워크스페이스 중 주 사용 환경을 지정합니다. 추후 좌측 사이드바에서 언제든 전환 가능.

Section 02

플랫폼 구조 한눈에 보기

ISP는 두 개의 주 모듈과 이를 떠받치는 공통 인프라 레이어로 구성됩니다. 모듈 간 데이터·모델·로그는 단일 거버넌스 정책 아래에서 흐릅니다.

Module · MLOps
모델 개발 콘솔

학습·평가·배포·모니터링 등 머신러닝 라이프사이클 전 과정을 표준 파이프라인으로 운영합니다. 개인 워크스페이스(AX)에서 노코드 에이전트 빌더도 사용 가능.

Module · LLMOps
수사 보조 LLM

자체 호스팅 LLM과 에이전트를 활용한 대화형 수사 보조 환경. 사내 DB·RAG·외부 도구 호출은 모두 정책 엔진을 거치며, 대화 전체가 감사 로그로 보관됩니다.

Layer · Data
데이터 거버넌스 레이어

온톨로지·리니지·목적 제한·접근 통제를 통합 관리. 데이터는 항상 분류 등급과 출처가 라벨링된 상태로만 모델에 노출됩니다.

Layer · Compute
GPU·K8s 자원 풀

A100/H100 클러스터를 부서·과제 단위 쿼터로 분할 운영. vLLM 라우터가 트래픽을 모델별로 분산하며, SLO 미달 시 자동 스케일 아웃합니다.

Section 03

MLOps 콘솔 사용 흐름

일반적인 모델 라이프사이클은 다음 다섯 단계를 거칩니다. 각 단계는 별도 화면에서 완결되며, 진행 상황은 우측 패널의 파이프라인 트리에서 실시간 확인됩니다.

  1. 데이터셋 등록
    데이터 탭에서 원본을 업로드하거나 사내 데이터레이크에서 가져옵니다. 등록 시 분류 등급·출처·보존 기간을 반드시 입력해야 다음 단계로 진행됩니다.
  2. 학습 작업 정의
    템플릿(분류 / 검출 / OCR / 임베딩 / LoRA 파인튜닝) 중 선택하거나 사용자 YAML을 업로드합니다. GPU 수량·예상 소요·예산을 입력하면 자원 관리자가 자동 큐잉합니다.
  3. 평가 리포트 확인
    학습이 끝나면 자동 평가 셋이 실행되어 정확도·재현율·공정성 지표(연령·성별·지역 편향)가 생성됩니다. 「영향 평가(AIA)」 통과가 배포의 전제 조건입니다.
  4. 승인 요청
    DEVELOPER가 배포 요청을 제출하면 APPROVER(부서장 + 정보보안담당관)에게 자동 라우팅됩니다. 승인까지의 모든 코멘트와 결재선이 로그로 남습니다.
  5. 배포 · 모니터링
    승인 후 카나리(5%) → 점진 롤아웃 → 100%로 진행됩니다. 운영 중에는 드리프트·지연·에러율을 30초 간격으로 모니터링하며, 임계치 초과 시 자동 롤백합니다.
주의 평가 단계에서 공정성 지표가 임계치를 벗어나면 승인 요청 자체가 차단됩니다. 차단 사유는 평가 리포트 하단에 명시되며, 데이터 재구성 또는 손실함수 가중치 조정 후 재학습이 필요합니다.

Section 04

LLM 워크스페이스 사용법

LLM 워크스페이스는 일반 대화형 인터페이스와 유사하지만, 모든 요청이 정책 엔진을 거쳐 모델로 전달됩니다. 다음 세 가지를 반드시 숙지하십시오.

① 분류 등급 선언

새 대화 시작 시 상단의 분류 셀렉터에서 이번 대화의 최대 취급 등급(A/B/C)을 지정합니다. 선언한 등급보다 높은 데이터가 입력으로 감지되면 자동으로 마스킹되며, 정보보안담당관에 알림이 전송됩니다.

② 에이전트 선택과 RAG

사이드바에서 에이전트 라이브러리를 통해 업무 영역에 맞는 사전 정의 에이전트(차량 추적·통신 분석·전과 조회 등)를 선택합니다. 에이전트가 사내 DB나 외부 도구를 호출하면 답변에 출처 인용 카드가 함께 표시되며, 출처를 클릭하면 원본 레코드까지 추적 가능합니다.

③ 대화의 감사 보존

모든 대화는 영구 보관되며, 사용자 본인이 삭제할 수 없습니다. 임시 대화가 필요한 경우 「검토용 세션」 모드를 사용하십시오 — 30분 후 자동 만료되지만 대화 로그는 동일하게 감사 시스템에 저장됩니다.

금지 행위 피해자·피의자의 개인정보를 그대로 프롬프트에 입력하지 마십시오. 입력 단계에서 자동 마스킹(이름·주민번호·연락처)이 적용되지만, 우회 시도는 징계 사유에 해당합니다.

Section 05

노코드 에이전트 빌더

MLOps 콘솔 → 내 워크스페이스 → 에이전트 빌더에서 코드 작성 없이 에이전트를 구성할 수 있습니다. 각 블록은 정책 엔진이 자동으로 검사하므로, 권한 외 데이터에 접근하는 도구는 캔버스에 놓을 수 없습니다.

Block · Trigger
트리거

대화 입력·웹훅·스케줄(크론) 중 선택. 외부 시스템 웹훅은 정보보안담당관 사전 등록 필수.

Block · Tool
도구 호출

사내 DB(KICS·CMS·SCAS), 외부 API(통신사·차량등록), 내부 모델(plate-enhance, k-ocr-v3 등) 호출 블록.

Block · LLM
LLM 추론

vLLM 라우터로 전달. 프롬프트 템플릿은 버전 관리되며, 변경 시 자동 diff가 표시됩니다.

Block · Policy
정책 게이트

분류 등급·목적 제한·인적 검토 필요 여부를 분기. 위반 시 호출이 차단되고 사유가 사용자에게 노출됩니다.

Section 06

감사 로그 조회

본인의 활동 이력은 우측 상단 아바타 → 내 활동 로그에서 누구나 열람 가능합니다. 타인의 로그 또는 부서 전체 로그는 APPROVER 이상 권한이 필요합니다.

정보보안담당관실은 별도의 SIEM 콘솔에서 모든 활동을 실시간 분석하며, 비정상 패턴(대량 다운로드·심야 접근·권한 외 데이터 조회) 감지 시 자동으로 세션을 종료하고 사후 면담을 요청합니다.

Section 08

자주 묻는 질문

외부망 노트북에서도 사용할 수 있나요?

불가합니다. 본 시스템은 경찰 내부망(KICS-Net) 전용입니다. 외근 중에는 모바일 폴리스원 단말의 「현장 에이전트」 앱을 사용하십시오 — 기능은 제한적이지만 동일한 감사 정책이 적용됩니다.

학습 데이터에 민원인 사진을 직접 업로드해도 되나요?

원칙적으로 금지입니다. 모든 인물 사진은 정보화기획단 비식별화 게이트웨이를 통과해야 데이터셋에 등록할 수 있습니다. 비식별화 처리 요청은 콘솔의 데이터 → 전처리 요청 메뉴에서 가능합니다.

LLM이 잘못된 출처를 인용했을 때 어떻게 신고하나요?

출처 인용 카드 우측의 「오류 신고」 버튼을 누르면 해당 추론 트레이스 전체가 모델 운영팀에 전달됩니다. 신고는 익명 처리되며, 동일 패턴이 3회 이상 신고되면 모델은 자동으로 「검토 보류」 상태로 전환됩니다.

내가 만든 에이전트를 다른 부서와 공유할 수 있나요?

가능합니다. 단, 공유 전에 APPROVER의 검토를 받아야 하며, 공유 대상 부서의 데이터 분류 등급이 에이전트의 작동 등급보다 낮은 경우 자동 차단됩니다.

GPU 자원이 부족해 학습이 계속 대기 중입니다.

대기 큐는 부서별 쿼터와 우선순위(긴급·일반·연구)에 따라 처리됩니다. 긴급 수사용 학습은 사이버수사대장 승인으로 우선순위를 상향할 수 있으며, 신청은 자원 관리 → 긴급 큐 요청에서 가능합니다.

대화 내역을 외부 보고서에 인용해도 되나요?

대내전용 자료로 분류되어 있어 외부 반출은 원칙적으로 금지됩니다. 보고서 인용이 필요한 경우 정보화기획단에 「반출 검토 요청」을 제출하시면 비식별화·요약 처리된 사본을 받을 수 있습니다.
